# 💬 BlueBytes
A peer-to-peer Bluetooth chat application for Android that enables real-time messaging without internet connectivity.

## ✨ Features

- **📱 Device Discovery** — Scan and discover nearby Bluetooth devices
- **🔗 Easy Pairing** — Streamlined pairing flow with connection management
- **💬 Real-Time Chat** — Send and receive messages instantly over Bluetooth Classic
- **💾 Message Persistence** — Chat history stored locally with Room database

## 🛠️ Tech Stack

| Category | Technologies |
|----------|-------------|
| **Language** | Kotlin |
| **UI** | Jetpack Compose, Material 3 |
| **Architecture** | MVVM + Clean Architecture |
| **Connectivity** | Bluetooth Classic |
| **Database** | Room |
| **DI** | Dagger Hilt |
| **Async** | Kotlin Coroutines, Flows |
